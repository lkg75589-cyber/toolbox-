# 🧰 Toolbox 30
30 أداة بايثون (Flask) بدون مفاتيح API، تتحول إلى تطبيق أندرويد APK عبر GitHub Actions.

## بناء الـ APK
1. ارفع الملفات للـ repo (الفرع main).
2. تبويب **Actions** → **Build APK** → **Run workflow**.
3. بعد 20-40 دقيقة افتح التشغيلة الناجحة ونزّل **toolbox-apk** من Artifacts (ملف zip فيه الـ APK).
4. ثبّت الـ APK على الموبايل (فعّل "التثبيت من مصادر غير معروفة").

## تشغيل على الكمبيوتر
pip install -r requirements.txt && python main.py
